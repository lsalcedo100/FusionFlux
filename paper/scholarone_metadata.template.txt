  Nuclear Fusion runs single-anonymous review: the referee sees the author, the
  author does not see the referee. There is no choice to make at the upload
  form, so the named build is the one that goes.

  An earlier version of this sheet said double-anonymous was IOP's default
  across the portfolio and single-anonymous the opt-out, and the cover letter
  told the editor the submission was double-anonymous. Both were wrong. IOP
  runs three models and sets no portfolio default; it is Plasma Physics and
  Controlled Fusion, not Nuclear Fusion, that offers the author a choice.
  Asserting a factual error about the journal's own review model, in the first
  paragraph an editor reads, is a worse opening than any framing gained by
  getting it right. CHECK THIS ON THE ABOUT PAGE AND THE SUBMISSION FORM
  BEFORE UPLOADING rather than trusting this paragraph, which is what the
  previous one earned.

  UPLOAD THE LINE-NUMBERED BUILD. `make review-pdf` writes build/review/, which
  is these two documents with lineno switched on. Referees on a manuscript this
  long will want to write "p. 23, line 6" and cannot without them. The committed
  PDFs deliberately have no line numbers, because the same source produces the
  PDF the DOI archives, where numbered lines are wrong; the review target
  switches them on without touching either committed file.
